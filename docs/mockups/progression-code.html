Vos choix de M26, le pourcentage seul. Chaque graphique est dessiné par son ambiance, dans un cadre isolé — exactement comme il tournera dans Sindry. « Animer » fait défiler un entretien : regardez la jauge glisser d'une valeur à l'autre, et la roue, la planète, la grille continuer sans à-coup.

BComment ça se code

Une section progression dans le fichier de l'ambiance, à côté du décor, avec les mêmes règles. Le code ci-dessous est celui qui tourne au-dessus.

Ce que Sindry donne au graphique

{{pourcentage}}
Remplacé par « 50 % », écrit comme il faut dans la langue de l'interface.
--p, --pct
La progression, de 0 à 1 et de 0 à 100. Elles glissent d'elles-mêmes de l'ancienne valeur à la nouvelle : rien à animer.
--depuis
Les secondes écoulées depuis le début. Une animation qui tourne en boucle s'en sert pour continuer d'une action à l'autre : animation-delay: calc(var(--depuis) * -1s).
data-etat, data-mode
Sur la racine : en-cours, fini ou arrete ; clair ou sombre.
var(--acc), var(--text)…
Tous les jetons de couleur de l'ambiance, comme dans le décor.
place
pastille : 88 × 88, dans l'en-tête de la carte. bandeau : toute la largeur de la carte, 150 de haut.

Les règles du décor. Un cadre isolé, sans script ni réseau ; le vérificateur refuse le reste. Sindry le recompose à chaque action terminée. Une ambiance sans progression a la barre de Sindry.
