## Nouveautés

### La mise à jour se fait dans Sindry

« Installer » ouvre maintenant une fenêtre de Sindry, qui suit quatre étapes : le
téléchargement, la vérification de la signature, l'installation, puis le redémarrage de
Sindry. La fenêtre de l'installeur Windows n'apparaît plus.

- Windows demande toujours l'autorisation d'installer, si Sindry n'est pas déjà
  administrateur : la fenêtre vous le dit avant.
- Si vous refusez, rien ne change, et Sindry le dit.

### La notification de mise à jour se voit aussi dans les réglages

La page des réglages ne recouvre plus les bandeaux en haut de la fenêtre.

### Une barre du haut qui tient dans une petite fenêtre

Quand la fenêtre rétrécit, la barre se resserre un cran à la fois : la version passe sous
le nom, la recherche raccourcit, les boutons prennent un libellé court (« Simu »,
« Admin »). Le thème, le journal, l'aide, puis les réglages passent dans un menu « ⋯ ».
Les boutons réduire, agrandir et fermer restent toujours visibles.

### Les réglages d'une action en onglets (Expert)

Une action qui a beaucoup de réglages les range maintenant en onglets, avec des
sous-titres. Le dernier onglet, « Sindry », garde le point de restauration et les
exceptions.

### Réglages

- 1.6 : numéroter les réglages des actions (« 2.3 » = 2ᵉ onglet, 3ᵉ réglage) : jamais,
  au-delà de 10 réglages (par défaut), ou toujours.
- 1.7 : toujours démarrer en administrateur. Windows le demande à chaque lancement.

### Pour les auteurs de scripts

- `[section:Cle]` range un réglage dans un onglet, `[section:Cle.Sous]` sous un
  sous-titre ; chaque section se déclare dans `REPORT` : `## Cle : [section] Titre —
  sous-titre`.
- Le validateur relève `SECTION_INCONNUE`, `SECTION_ORPHELINE`, et conseille des sections
  au-delà de 10 réglages.
- Guide pour IA : la règle 44, et l'entrée 2.2.0 de `SCRIPTS_POUR_IA_NOUVEAUTES.md`.
- Détails dans `docs/FORMAT_SCRIPT.md`, « Ranger les réglages en sections ».
