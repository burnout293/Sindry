## Nouveautés

### Un nouvel écran pour les longues listes

Quand une analyse trouve beaucoup de choses, elles s'affichent maintenant dans un seul
écran, plus facile à parcourir :

- deux onglets : **Choisir**, et **Récapitulatif** pour relire ce qui sera fait ;
- une **recherche** ;
- des **catégories**, une à la fois : Navigateurs, Bureautique… ou Programmes, Démarrage… ;
- un bouton **Filtres et tri** : trier par catégorie, par nom, par recommandation ou par
  éditeur, et choisir les étiquettes affichées.

### Des explications sur ce qui est proposé

Pour chaque élément qu'il propose de retirer, un script peut maintenant dire **de quoi il
s'agit**, **pourquoi** il le propose, et **à quoi faire attention**. Cliquez sur une ligne :
sa fiche s'ouvre à droite.

- Ce qui est **à double tranchant** ou **déconseillé** (un antivirus, par exemple) n'est
  jamais coché d'avance. Un élément déconseillé demande une confirmation.
- Ce qui demande un **redémarrage** est signalé dans la fiche, dans le récapitulatif et
  avant de lancer.

### Les icônes des applications

Les applications à installer montrent leur icône officielle. Elle vient d'un seul endroit,
le dépôt Sindry-Media-Library, et Sindry les demande toutes, sans dire ce qui est installé
chez vous. Pour ne rien télécharger : Réglages › Catalogues › 3.3.

### « Ce qui sera fait »

La liste est maintenant complète, regroupée et illustrée. Elle s'affiche aussi en mode
Simple, sous l'analyse.

### Pour les auteurs de scripts

- `[ITEM] … about=`, `why=`, `warn=` : la fiche de l'élément (des notes du bloc `REPORT`).
- `advice=caution` ou `discouraged` : jamais coché d'office.
- `reboot=true` : le redémarrage annoncé d'avance.
- `icon=` (une icône Lucide) et `appicon=` (l'icône officielle d'une application).
- Le validateur relève une note inconnue (`ITEM_TEXTE`).
- Détails dans `docs/FORMAT_SCRIPT.md`.
