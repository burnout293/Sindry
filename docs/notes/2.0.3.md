## Nouveautés

### Des erreurs expliquées

Quand une action échoue, Sindry dit maintenant **pourquoi**, dans votre langue, et
**quoi faire** : « Accès refusé sur une clé protégée — Redémarrez le PC, puis relancez
l'action ». L'explication apparaît dans le journal et sur la tâche en échec.

### La vraie icône des programmes

Dans les listes de l'analyse, un programme montre sa propre icône, lue sur votre PC.
Rien n'est envoyé ni téléchargé.

### Pour les auteurs de scripts

- Codes d'erreur traduits : `[error]` dans le bloc `REPORT`, `[ERR] E104 …` en sortie.
- Auteur et dates dans l'entête (`author`, `created`, `updated`), affichés dans la fiche
  de l'Expert.
- `[ITEM] … exe=` : le programme dont afficher l'icône.
- Détails dans `docs/FORMAT_SCRIPT.md`.

### Désinstallation

Une case de plus : « Données de restauration des actions ».
