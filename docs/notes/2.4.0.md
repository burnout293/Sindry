## Nouveautés

### Une version portable, sur une clé USB

Sindry existe maintenant sans installation : une archive à décompresser, sur une clé USB
ou dans un dossier, et Sindry se lance de là.

- Rien ne s'installe sur le PC : réglages, catalogues, scripts et journaux vont dans le
  dossier `Donnees`, à côté de Sindry.
- Ce qui protège le PC (approbations des scripts, emplacements protégés) reste dans le
  PC, et ne se modifie qu'en administrateur.
- Pour mettre à jour, Sindry ouvre la page des versions : remplacez les fichiers par ceux
  de la nouvelle archive, en gardant `Donnees`.
- Si une action redémarre le PC, rouvrez Sindry depuis la clé : il propose de reprendre.

### Les nouveautés, dans Sindry

Après une mise à jour, Sindry montre ce qu'elle apporte, une fois. Toutes les versions
de Sindry 2 restent à lire dans l'aide, « Les nouveautés ».

### Une fenêtre plus grande

Sindry s'ouvre sur 90 % de l'écran, centré.

### Une barre du haut plus calme

L'aide, le journal, le thème et les réglages sont rangés dans un menu « ⋮ », à droite.
Simple et Expert, la simulation et les droits restent toujours visibles.

### La liste des scripts (Expert)

- **Trier** : par catégorie, de A à Z, les plus récentes d'abord, ou par numéro (ID).
  Sindry retient votre choix.
- Un menu **« ⋮ »** : ouvrir le dossier des scripts, actualiser la liste, mettre à jour les
  catalogues, ajouter un script ou un catalogue.
- **Ajouter un script** copie un fichier `.ps1` dans vos scripts ; il vous est montré avant
  sa première exécution, comme tout script personnel.
